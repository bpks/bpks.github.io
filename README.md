# Portfolio site

A single-page personal portfolio: `index.html` (inline CSS and a few lines of JavaScript, no build step, no
external requests, light and dark themes, works at phone width).

## Preview

Open `index.html` in a browser, or serve the folder: `python -m http.server` and visit `http://localhost:8000`.

## What is deliberately not on the page

No email address, phone number, home location, notice period, clearance status or client names. Contact is
through LinkedIn and GitHub only. Experience is limited to the two most recent roles.

## Before publishing

- The featured-project links point to `https://github.com/bpks/health-data-platform`, so that repository must
  exist first (search for `health-data-platform` if the name changes).
- The career figures (25+ pipelines, 28%, 30% and so on) describe professional work and are labelled as separate
  from the demo project's own numbers.

## Publishing on GitHub Pages

A repository named `bpks.github.io` containing these files is served at `https://bpks.github.io`.
